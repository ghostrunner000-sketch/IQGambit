Stockfish Max uses the official Stockfish.js v19.0.1 single-threaded full engine build.

Source: https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1
Engine project: https://stockfishchess.org/
License: GNU General Public License version 3 (GPL-3.0-or-later); see Copying.txt.

The full WebAssembly engine is approximately 95 MB and is loaded only when Stockfish Max is selected. Browser security requires this website to be served over HTTP or HTTPS; opening index.html directly as a file uses the local practice-engine fallback.
